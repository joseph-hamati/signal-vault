# Signal Vault

A first-person digital systems learning game based on Modules 5 and 6, Part 1 of Introduction to Cybersecurity.

## Play

Open `index.html` or serve the files locally. Move with WASD, the arrow keys, or the on-screen controls. Open the terminal with E and select a work order. The map provides fast travel between sectors.

Explore 12 sectors with 72 work orders. Rebuild signal chains, load positional registers, operate conversion machinery, wire gates and selectors, clock flip-flops and counters, and execute bitwise instructions against live data. Commissioning tests verify the built device and report the first failing socket, input combination, or time step. Restore all 12 sectors to unlock five final city-uplink operations. Completed work orders and the best exam score are stored on your device.

A separate 20-question practice exam gives explanations after grading. Eight integration questions are paired with 12 randomized sector questions.

## Deploy to GitHub Pages

Commit the files at the repository root. In **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save. GitHub displays the published URL after deployment. The site requires no build or dependencies.

## Source material

Original study explanations and practice based on *05-Numbering Systems* and *06-Module_six Digital Systems and Logic Design - part1*, Dr. Marwan Alakhras, Applied Science Private University.
