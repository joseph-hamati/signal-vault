# Signal Vault

A first-person digital systems study campaign based on Modules 5 and 6, Part 1 of Introduction to Cybersecurity. All lessons, exercises and art ship as a static site.

## Play

Open `index.html` or serve the files locally. Move with WASD, the arrow keys, or the on-screen controls. Press E or click Open terminal to read the current sector's notes and start its mission. The sector map provides fast travel.

Restore 12 sectors through 60 mission challenges. Practice mode generates fresh problems. Six circuit benches let you manipulate logic gates, an adder, a MUX, a DEMUX, a D flip-flop and bit masks. The final exam combines 12 generated problems with eight integration problems, with graded explanations after submission. Progress uses browser local storage.

## Deploy to GitHub Pages

Commit the files in this directory at the repository root on `main`. In **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save. GitHub displays the published URL on that page after deployment. The site uses relative URLs and requires no build or dependencies.

## Source material

Original study explanations and practice based on *05-Numbering Systems* and *06-Module_six Digital Systems and Logic Design - part1*, Dr. Marwan Alakhras, Applied Science Private University.

Module 5 slide 15 has an arithmetic inconsistency. The campaign uses 1ACF₁₆ = 6863₁₀; 23247₁₀ equals 5ACF₁₆.
